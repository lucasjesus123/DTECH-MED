# Imagem: usar o KAIROGEN

Quando precisar CRIAR imagem para este projeto, use o **KAIROGEN** (servidor MCP
`mcp__KAIROGEN__*`). É a ferramenta escolhida pelo dono do projeto.

Ele custa crédito da conta dele. Então: `estimate_cost` primeiro, **diga o valor
em créditos, e só depois gere**. Nunca saia gerando para "ver como fica".

## Onde imagem gerada serve

Ilustração e apoio visual — imagem de compartilhamento (o card do link no
WhatsApp), ícones, fundos, peças de tela — e fotos de aparelho e de peça para o
cenário de ENSAIO.

## Onde ela NÃO entra, nunca

**Nada que ocupe o lugar de um registro:** foto de recebimento, foto de laudo,
assinatura de cliente, documento de O.S.

Numa ordem de serviço essas imagens não ilustram — elas SÃO a prova. A folha de
rastreabilidade (`/painel/equipamentos/[id]/rastreabilidade`) conta ao cliente,
ao fabricante e à vigilância sanitária quantas provas existem e de que dia são.
Uma imagem gerada ali dentro não seria enfeite: seria prova falsa, num sistema
cuja razão de existir é responder "quem mexeu neste aparelho" com honestidade.

Se algum dia parecer que é preciso imagem nesse lugar, **pergunte antes**.
